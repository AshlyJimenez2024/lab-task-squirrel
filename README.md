# 📸 Photo Task Viewer  

This is a small iOS project I worked on where the main idea is simple:  
open up a task → see the photo attached to it.  

The project uses **Swift + UIKit** and is basically a lightweight demo of how to connect a `UIViewController` to a storyboard element (`UIImageView`), load data into it, and handle the iOS app lifecycle with `SceneDelegate`.  

---

## 🌟 What it Does
- Lets you view a photo tied to a `Task`.  
- Minimal design — just the image you care about.  
- Scene management built in (so it plays nicely when the app moves between active, background, etc.).  

---

## 🗂️ Files in This Project
- **PhotoViewController.swift** → handles showing the task’s image inside a `UIImageView`.  
- **SceneDelegate.swift** → iOS lifecycle boilerplate (foreground, background, inactive states).  
- **Contents.json** → asset catalog metadata (Xcode auto-generated).  

---

## 🔧 How to Run
1. Open the project in **Xcode** (13+).  
2. Build & run on the simulator or a real iPhone.  
3. Navigate to a task → the photo displays instantly.  

---

## 💡 Why I Made This
I wanted to practice:  
- Hooking up storyboard UI to code with `@IBOutlet`.  
- Passing data between views (in this case, a `Task` with an image).  
- Understanding how `SceneDelegate` fits into modern iOS apps.  

---

## 🚀 Possible Next Steps
- Add a task list to pick from.  
- Let users add their own photos.  
- Save tasks/images with Core Data or UserDefaults.  

---

✨ Just a small project, but a good step in learning iOS development.
